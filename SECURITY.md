# Security Policy

## Supported Versions

| Version | Supported          |
|---------|--------------------|
| 0.4.x   | :white_check_mark: |
| < 0.4   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in usecvislib-mcp, please report it responsibly.

**Do NOT open a public GitHub issue for security vulnerabilities.**

Instead, please send an email to **security@vulnex.com** with:

- A description of the vulnerability
- Steps to reproduce the issue
- The potential impact
- Any suggested fixes (optional)

## Response Timeline

- **Acknowledgment**: Within 48 hours of receiving your report
- **Initial assessment**: Within 5 business days
- **Fix and disclosure**: We aim to release a fix within 30 days for confirmed vulnerabilities

## Scope

This policy covers the usecvislib-mcp MCP server, including:

- Authentication and authorization mechanisms
- Input validation and sanitization
- Path traversal and file access controls
- Rate limiting and resource management
- Docker container security

## Acknowledgments

We appreciate responsible disclosure and will credit reporters in the CHANGELOG (unless you prefer to remain anonymous).
